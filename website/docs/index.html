Install Premiere Pro MCP

Premiere Pro MCP is the original local MCP server for Adobe Premiere Pro. The npm package is adobe-premiere-pro-mcp. The CLI is premiere-pro-mcp. This page is the install and compatibility guide for premiere-mcp.com. You need Node.js 20+ and Premiere Pro 2020+ on the same computer as the MCP client.

Install from npm

npm install -g adobe-premiere-pro-mcp. Then premiere-pro-mcp --install-cep and premiere-pro-mcp --doctor. Register an MCP server named premiere-pro with command premiere-pro-mcp. Restart the client if it only reads config at launch.

Start the CEP bridge

Restart Premiere. Open Window → Extensions → MCP Bridge (CEP). Set the temp directory the installer printed. Start Bridge and wait until the panel is green.

First prompt

Run verify_premiere_connection. Make no changes. Then use search_tools and invoke_tool. Do not invent tool names.
