Privacy — Premiere Pro MCP

Premiere Pro MCP is local software. It does not operate a hosted editing service and does not send Premiere project data, media, MCP request arguments, or tool results to the project maintainers.

The MCP server and CEP bridge exchange command and response files in a local bridge directory you choose. That data stays on your computer unless you share it. Optional anonymous telemetry records tool name, success, and duration only. It does not include project names, media paths, or usernames. Turn it off with PREMIERE_MCP_TELEMETRY=0 or uncheck Share anonymous usage data in the CEP panel. Privacy questions go to GitHub issues.
