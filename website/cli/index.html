Premiere Pro MCP CLI

The official CLI for Premiere Pro MCP is premiere-pro-mcp, published on npm as adobe-premiere-pro-mcp. Run npm install -g adobe-premiere-pro-mcp, then premiere-pro-mcp --install-cep and premiere-pro-mcp --doctor.

premiere-pro-mcp starts the local MCP server that Cursor, Claude, Codex, and other clients spawn. --install-cep copies the production CEP bridge into Premiere. --doctor checks Node, the CLI on PATH, and the CEP install. This is not a remote HTTP API. Install the CLI on the same machine as Premiere, register premiere-pro, then run verify_premiere_connection.
