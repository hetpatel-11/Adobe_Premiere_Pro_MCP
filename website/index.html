Premiere Pro MCP

Premiere Pro MCP is the original open-source local MCP server for Adobe Premiere Pro. The canonical site is premiere-mcp.com. The npm package is adobe-premiere-pro-mcp. The official CLI is premiere-pro-mcp. 283 tools talk to Premiere through a CEP file bridge on the same machine. Cursor, Claude, Codex, and Claude Code stay local. Footage never leaves disk.

When to use Premiere Pro MCP

Use it when an agent needs to edit a local Premiere Pro timeline: insert or overwrite clips, trim, razor, move, apply effects, import media, or queue an export. Do not use it for remote Premiere, After Effects, or hosted media APIs.

Install

npm install -g adobe-premiere-pro-mcp then premiere-pro-mcp --install-cep and premiere-pro-mcp --doctor. Register an MCP server named premiere-pro with command premiere-pro-mcp. First prompt: Run verify_premiere_connection. Make no changes.
